Execução do programa:

1 - Clonar o repositório para a máquina (ver README_repositorio);
2 - Abrir o VsCode;
3 - Localize o diretório "Avaliacao5_3TRI";
4 - Abra o diretório localizado;
5 - Execute o terminal do VsCode (pode ser acessado pelas teclas de atalho crl + ');
6 - No terminal, acesse a pasta onde se localiza o algoritmo digitando o seguinte comando:
    6.1 - VsCode: "cd Avaliacao5_3TRI\apartamento_db";
7 - Verifique se os módulos necessários estão inseridos digitando os seguintes comandos (no Terminal):
    7.1 - VsCode: PS C:\... uv add mysql;
    7.2 - VsCode: PS C:\... uv add pymysql;
    7.3 - VsCode: PS C:\... uv add sqlalhemy;
    7.4 - VsCode: PS C:\... uv add dotenv;
8 - Execute o algoritmo digitando o seguinte comando (ainda no Terminal):
    8.1 - VsCode:  PS C:\... uv run apartamento_morador.py;
